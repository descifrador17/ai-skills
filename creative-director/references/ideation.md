# Ideation + Rejection Loop

Condensed from Hermes `creative-ideation` (SHL0MS, MIT), adapted for motion pieces.

## Route before you generate

Read the phase from the request, then pick ONE method (two only when signals contradict — say so explicitly).

| Situation | Method |
|---|---|
| No concept yet, brief known | **Story skeletons** — pick a shape, then fill it |
| "Make it less obvious / weirder" or slop terrain (app promo, SaaS launch, AI anything) | **Lateral provocations (de Bono PO)** — refuse first 5, not 3 |
| Has a draft that feels flat | **Oblique Strategies** — draw one card, apply literally |
| Has a base idea, wants variations | **SCAMPER** |
| Needs a visual metaphor | **Analogy + conceptual blending** |
| Choosing between concepts | **Premortem + inversion** |

### Story skeletons for short motion (pick one, name it)
- **Problem → turn → proof** — the default; usually lands in Rejected unless the turn is surprising.
- **Single-object journey** — one element travels through every shot; cuts are match-cuts on it.
- **Reveal by subtraction** — start dense/noisy, remove until only the product remains.
- **Inversion** — show the world *without* the product as the strange one.
- **Ritual** — one repeated action, varied each time, broken once at the wow.
- **Scale jump** — micro detail → impossibly macro (or reverse) on one continuous move.
- **Typographic score** — text is the only actor, timed to audio like notation.

### De Bono PO operators
State `Po: <provocation>`, list 5 consequences, keep the strongest, translate into a shot.
- **Escape:** "Po: the reading app never shows a book."
- **Reversal:** "Po: the book reads the reader."
- **Exaggeration:** "Po: the video is one continuous 20-second zoom."
- **Distortion:** "Po: the end card plays first."
- **Wishful:** "Po: the phone is the shelf."

Random-word variant: take a genuinely random noun (not "innovation"), list 5 links to the problem, use the strongest.

### Oblique Strategies (sample — draw, don't choose)
Honor thy error as a hidden intention · Use an old idea · What would your closest friend do? · Emphasize the flaws · Only one element of each kind · Remove specifics and convert to ambiguities · Repetition is a form of change · Do nothing for as long as possible · Reverse · Use fewer notes · What is the reality of the situation? · Make a sudden, destructive unpredictable action; incorporate

## Anti-slop signatures (motion edition)

Reject a concept if it is mostly:
- Fade-in → slide-up headline → feature chips → logo → CTA
- Phone mockup floating in gradient void, rotating 15°
- Glowing particles / bokeh as "premium"
- Every element springs in with the same default
- Words like *seamless, powerful, effortless, unlock, journey* in on-screen copy
- A concept that survives swapping the product name for any competitor's

### Five-test (every concept)
1. Swap one noun — does it still fit a different product? → slop
2. Names a real mechanism, material, place, or work? → if no, slop
3. One element needs explaining? → if no, slop
4. Can you describe a frame in concrete sensory terms? → if no, slop
5. Would a sharp motion designer be embarrassed to pitch it? → slop

Fail 2+ → regenerate.

## Concept card (required shape)

```
### C<n>: <title> — method: <name>
Premise:      <one sentence>
Skeleton:     <story skeleton>
Wow moment:   <the ONE moment, with timestamp>
Visual system:<palette logic, type, material, camera>
Mechanism:    <how Remotion builds it — Sequence/TransitionSeries, SVG path, @remotion/three, captions, data>
Failure mode: <honest: how this goes wrong>
Grounded?:    yes/no
```

Three presented concepts must differ on **≥2** of premise, skeleton, tone cell, visual system.

## Scoring rubric (1–5)

| Criterion | 1 | 5 |
|---|---|---|
| Originality | Fails five-test | Passes all five, survives no noun-swap |
| Brief fit | Off-message | Delivers the ONE message unaided |
| One-wow clarity | No peak / two peaks | Single peak, nameable in 5 words |
| Remotion feasibility | Needs footage/3D you don't have | Buildable with current assets in the time box |
| Variant survival | Breaks in 9:16 | Composes for every planned aspect |

Originality ≤ 2 → cut, regardless of total. Report all scores in a table.

## Premortem (leader only, 3 lines)
"Launch day. Nobody watched past second 3 because…" / "…people misunderstood it as…" / "…it was indistinguishable from…". Each line yields a fix or a demotion.

## Rerolls
If no concept lands, **switch method**. Same method = same distribution of ideas.
